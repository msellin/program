## HOUSE RULES THAT WILL BITE YOU

- **`npm run verify` from `next-app`** before every commit. The pre-commit
  hook runs it. Any edit under `next-app/public/data/` must pass — JSON that
  parses is not JSON that validates.
- **Regenerate the reviewer packets** after touching programme data:
  `python3 dev/scripts/build-reviewer-packet.py`. A fingerprint test fails
  otherwise, and it caught real drift three times today.
- **Zod strips unknown keys silently.** A field nothing reads is this repo's
  most-repeated defect. If you add one, write the test that proves something
  consumes it.
- **An unresolved `exercise_id` does not throw** — the movement silently
  vanishes from the workout. `data-integrity.test.ts` is the only thing that
  catches it. It caught one of mine today.
- **Mutation-test before you claim a fix works.** Break it deliberately; if
  the suite stays green, the test is decoration. This found two unguarded
  fixes today.
- **CI: match the run to your SHA.** `gh run list --limit 1` races and returns
  the PREVIOUS run; I reported a false success that way once.
- Never use `--no-verify`. Commit docs with code. Push to main.
