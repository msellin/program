# Screening decisions — rationale for every gate added or changed

**Decided 2026-09-03** under the founder's stated standard: scientifically
defensible, everything reasoned, no shortcuts. Each entry below traces to
either (a) the programme's own `evidence_base.contraindications`, which is the
founder's prior decision, or (b) a named argument from the SR-1..SR-4 panel.

**These are not clinical opinions and are not presented as any.** No human
clinician has reviewed them. Where a specific clinical threshold would be
needed, none was invented — the question asks about the symptom or the
diagnosis the programme already named, and the gate acts on that.

## The block-vs-warn rule

**Block** when the programme's own contraindication says avoid *entirely*, or
the hazard is acute and the user cannot resolve it before training.

**Warn** when the user can resolve the uncertainty (measure your BP, ask your
GP), or when the risk is a gradient rather than a threshold.

The reason warn exists at all, in SR-3's words: *"Bouncing them teaches them
to answer 'no' next time, which is strictly worse."* Over-blocking is not the
conservative direction — it produces dishonest answers, and a screen the user
has learned to lie to protects nobody. That is an argument about screening
behaviour, not a preference.

Absent severity still means block. Silence never loosens a gate.

## Decisions

### Block

| programme | question | why |
|---|---|---|
| first-strict-pullup, muscle-up | cervical radiculopathy | The file says "avoid dead hangs **entirely**". Dead hang is first-strict-pullup's Tier A backbone. The word "entirely" is the founder's own decision. |
| handstand-walk | recent concussion / vestibular disorder | Contraindicated in the file; the programme opens with a week of deliberately falling out of inversion. Acute, and not resolvable by the user. |
| muscle-up | acute wrist injury (6 weeks) | The file prohibits false-grip work outright, and false grip is the programme's foundation. `handstand-walk` already blocks on the same question — this mirrors an existing decision rather than making a new one. |
| overhead-mobility | adhesive capsulitis | The file says "separate rehab protocol". A programme cannot be both the protocol and not the protocol. |
| overhead-mobility | end-range shoulder pain = yes | SR-1's most consequential finding: the user is describing pain in exactly the range every phase of the programme trains. "Occasionally" warns instead — that is the gradient case. |
| first-strict-pullup, muscle-up | uncontrolled hypertension = yes | Mirrors the gate already shipping on four other programmes. Both prescribe sustained Valsalva at the top isometric. |
| engine-builder | joint_issue_severity = limits_all_cardio | The option's own label reads "see a clinician before starting". The label already decided; the gate never honoured it. |

### Warn, with a required acknowledgement

| programme | question | why |
|---|---|---|
| all five HR-prescribing | hypertension "unsure" | SR-3 and SR-4 independently: gate the intensity, not the programme. Z1/Z2 work is the correct recommendation for suspected uncontrolled hypertension; the hazard is in the maximal work. "Unsure" is overwhelmingly "I have not measured recently" — resolvable with a pharmacy cuff in 48 hours. |
| four HR-prescribing | **beta-blockers / rate-limiting medication** (new) | Not a clinical opinion: the drug blunts HR response, so a 90-95% HRmax target is unreachable and both HR retest metrics read as non-response for the entire block. Warn rather than block because the training is safe — it is the *measurement* that is invalid. Named first fix by two reviewers independently. |
| overhead-mobility | rotator_cuff_dx "unsure" | The honest answer of someone with pain and no diagnosis. Blocking teaches them to answer "no". |
| overhead-mobility | active AC-joint irritation | The file says end-range flexion "can amplify" it — a gradient, not an absolute. |
| handstand-walk | osteoporosis "unsure" | SR-2: most adults under 50 have never had a DEXA; blocking them would be absurd. |
| handstand-walk | persistent wrist pain (12mo) | The programme's own cited survey reports 56.7% chronic wrist pain in this population. Blocking would exclude most of it. |
| four programmes | first-trimester pregnancy | Every one of these files gives the same reason — "HR-based zones unreliable". That is a measurement-validity problem, not a danger, and pregnancy is the wrong place for a paternalistic hard block. Warn, name the reason, defer to their clinician. |

### Deliberately NOT decided here

- Every prescription change (eccentric volume caps, deliberate-fall surface,
  day-1 maximal 2K, CSM's contradictory block note). Coaching judgement.
- The terminology rewrite ("impingement" → RCRSP).
- Whether `submax_hr_pace5_bpm` survives as a primary signal.
- Any numeric clinical threshold. No BP cutoff, no age cutoff, no ROM
  threshold was invented. Questions ask about the diagnosis or symptom the
  programme already named.
