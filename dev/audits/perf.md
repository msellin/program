| Today: click "Add set"                                   | 58 ms     |
| Today: expand cues                                       | 79 ms     |
| Today: open video modal (includes YouTube iframe fetch)  | 5,072 ms  |
| Progress: type "120" into TM input                       | **227 ms** |

Today weight/reps keystroke ~110 ms warm; cost is Zustand deep-copying the full `Store` (`useStore.ts:66–76`) plus `saveStore(s)` writing the full log JSON to `localStorage`. The 198 ms first keystroke includes suggestion recompute — `suggestForExercise(...)` runs on every render of `ExerciseCard`, unmemoized.

**Progress TM edit at 227 ms is the worst hotspot.** Every keystroke:
1. Full Store copy + `localStorage` write (`setTM`, `useStore.ts:57–64`),
2. `ProgressPage` re-runs `evaluateCycleEnd` / `detectPauseResume` / `assessWaypoints` synchronously,
3. `SymptomLoadChart` rebuilds `rows`; Recharts re-renders the ComposedChart.

None expensive alone, but at 4× CPU that's 227 ms and would still be 60–90 ms per keystroke on a mid-range Android — right at the INP failure boundary.

## 8. Top 5 improvements, ranked by impact

1. **Lazy-load Recharts on `/progress/`.** Replace the top-level import with `const SymptomLoadChart = dynamic(() => import('@/components/charts/SymptomLoadChart').then(m => m.SymptomLoadChart), { ssr: false, loading: () => <div className="h-[300px] animate-pulse bg-line-soft rounded" /> });`. Removes 112 KB gz from Progress's critical path, cuts main-thread work 1.3 s → ~0.6 s, and drops the 91 KB Today prefetch. Expected Progress LCP -600 to -900 ms; Today unused-JS < 50 KB.

2. **Debounce store persistence.** `saveStore(s)` JSON-stringifies the full log on every keystroke. Wrap in a 250 ms debounce or move to `requestIdleCallback` (or adopt Zustand's `persist` middleware, which is smaller than the hand-rolled `loadStore/saveStore` pair). Biggest single win on INP.

3. **Memoize Progress TM re-render.** Wrap `SymptomLoadChart` in `React.memo`; derive `rows` in `useMemo` keyed on `store.logs`. Move `evaluateCycleEnd/detectPauseResume/assessWaypoints` into `useMemo(..., [store])` so a TM keystroke doesn't recompute cycle-end analytics. Target: TM keystroke ≤ 100 ms at 4× CPU.

4. **Memoize `suggestForExercise` in `ExerciseCard`.** Currently recomputed on every notes keystroke. `useMemo(() => suggestForExercise(...), [exercise.id, blockId, program, store.training_maxes[exercise.id], store.logs[activeDate], activeDate])`.

5. **Drop legacy transforms.** Lighthouse flags `Array.prototype.at/flat`, `Object.hasOwn` etc. polyfilled inside `254-*.js` at ~11 KB. Raise the `browserslist` floor in `next.config.ts` — Next 16 defaults still target older Safari. Free win.

Also worth doing: BottomNav prefetches all 8 routes on Today load. `<Link href="/progress/" prefetch={false}>` on the heavy tab reduces cellular waste for the many sessions where Progress is never opened.
